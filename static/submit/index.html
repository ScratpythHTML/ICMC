Put it on the website

  1. Unzip the file you just downloaded. You will get a folder called content.
  2. Go to the upload page on GitHub (sign in if it asks).
  3. Drag the content folder onto that page. GitHub will keep the folders in the right places.
  4. Scroll down and choose how to save it:
    • Most people: pick “Create a new branch and start a pull request” and click Propose changes. Someone on committee will check it over and publish it.
    • Admins: if you have write access you can skip the review and pick “Commit directly to the master branch” instead — that is the main branch this site is built from. It still needs the deploy to be run before it appears on the live site (see below).

Once it is merged, publish it from the Actions page — click Run workflow.

Photos can be large, so the upload may take a minute or two on a slow connection. If GitHub refuses the upload, it is usually because there are more than 100 files or the total is over 25 MB — ask on the committee chat and someone will add it for you.
